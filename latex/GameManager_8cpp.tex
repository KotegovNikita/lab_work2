\doxysubsection{Detailed Description}
Implementation of the \doxylink{classGameManager}{Game\+Manager} class – the central coordinator of a console‑based turn‑based card RPG. It is responsible for initialising decks, handling the main turn loop, controlling AI behaviour, checking win conditions and exposing helpers that other cards use to interact with the battlefield. 

The file also contains several small helper routines that are closely coupled to the manager logic (e.\+g. {\ttfamily can\+Add\+Card\+To\+Hand}). All comments follow the Doxygen style so the file can be fed directly to Doxygen without further changes.
