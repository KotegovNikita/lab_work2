\doxysubsection{Detailed Description}
Core controller of the game. 

Responsible for managing the game state, including decks, hands, fields, turn flow, and win conditions. Provides public interfaces for cards to interact with the board and handles logic for both player and AI turns.

Runs the AI\textquotesingle{}s decision-\/making logic for its turn. 

Decide and execute the AI move for the current turn.

The algorithm follows a simple priority scheme\+:
\begin{DoxyEnumerate}
\item Early game (first three AI turns) – summon any available character.
\item If no characters on the AI field – summon a character.
\item If the player controls a strong unit – attempt a direct attack card.
\item If any AI unit is hurt – apply a support/heal card.
\item Otherwise play a random card.
