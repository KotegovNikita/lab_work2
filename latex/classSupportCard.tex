\doxysubsection{Detailed Description}
Abstract base class for cards that apply beneficial effects (healing, buffs) to allies. 

Inherits from \doxylink{classCard}{Card}. Provides shared fields and methods for all support-\/type cards. Specific effects must be implemented in derived classes like \doxylink{classHeal}{Heal} or \doxylink{classBarrier}{Barrier}.
