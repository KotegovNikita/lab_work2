\doxysubsection{Detailed Description}
Abstract base class for all summonable character cards (e.\+g., \doxylink{classKnight}{Knight}, \doxylink{classMage}{Mage}, \doxylink{classRogue}{Rogue}). 

This class extends the \doxylink{classCard}{Card} interface by adding attributes such as attack and health, and mandates implementation of methods that define a character’s combat stats and summoning logic.
