\doxysubsection{Detailed Description}
Represents a card that deals direct damage to enemy characters. 

This abstract class is intended to be inherited by specific attack card types (e.\+g., Lightning\+Strike, \doxylink{classFlameWave}{Flame\+Wave}). It defines the basic interface and data for damaging effects.

Inherits from the base \doxylink{classCard}{Card} class.
