Detailed Description

Core controller of the game.

Responsible for managing the game state, including decks, hands, fields, turn flow, and win conditions. Provides public interfaces for cards to interact with the board and handles logic for both player and AI turns.

◆ aiMakeMove()

void GameManager::aiMakeMove ( )

Runs the AI's decision-making logic for its turn.

Decide and execute the AI move for the current turn.

The algorithm follows a simple priority scheme:

  1. Early game (first three AI turns) – summon any available character.
  2. If no characters on the AI field – summon a character.
  3. If the player controls a strong unit – attempt a direct attack card.
  4. If any AI unit is hurt – apply a support/heal card.
  5. Otherwise play a random card.

◆ runTurn()

void GameManager::runTurn ( )

Executes a full turn: player move, AI move, optional combat.

Execute one full round: player interaction → AI logic → draws → combat → end‑game check.

The body is quite verbose because of console I/O, yet the high‑level flow is:

  1. Player selects and plays a card (or skips on invalid input).
  2. AI chooses a move via aiMakeMove.
  3. Both sides draw one card.
  4. Optional single combat where the player initiates an attack.
  5. End‑game detection and winner announcement when appropriate.

◆ startGame()

void GameManager::startGame ( )

Starts a new game: initializes decks and hands.

Bootstraps a new match (decks → hands → first draw) and prints basic information.

This method

  1. Builds a fresh deck for both the player and the AI.
  2. Deals the full deck into the player/AI hands while respecting deck rules via dealCards and ensureMinimumAbilityCards.
  3. Displays initial hand sizes so that the user sees immediate feedback.
